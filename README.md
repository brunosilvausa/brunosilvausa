## 🕹️ The Origin Story

</div>

I grew up with **floppy disks, ball mice, Windows 98, CD-ROMs, dial-up internet, MSN Messenger, and LimeWire**.

Getting online had its own soundtrack.

And if someone picked up the phone?

That was it.

Back then, installing software could take several disks and a lot of patience.

Now I can describe an idea to AI and have a working prototype running before younger me would have finished installing a game.

That still feels slightly absurd.

And probably explains why I keep building things.

## 👨‍💻 What I Do

</div>

I'm a **business owner, tech enthusiast, and vibe coder** based in New York.

I'm not a traditional software engineer.

Most projects start with a simple question:

> **"Wouldn't it be useful if..."**

Then I use **AI, APIs, databases, automation, and web tools** to see if I can turn the idea into something real.

Sometimes it works quickly.

Sometimes the "simple idea" suddenly needs authentication, database rules, admin tools, logging, backups, and a completely different architecture.

That's usually where I learn the most.

## 🚀 Things I'm Building

</div>

### 🐾 Manhattan Petsitters

A local pet-services directory for people looking for dog walkers, pet sitters, groomers, trainers, boarding, and other pet services in Manhattan.

It started with:

> **"There should be a better way to find pet services in Manhattan."**

Then somehow it turned into authentication, provider onboarding, moderation, admin tools, search, storage, database security, and deployments.

You know.

A directory.

**Stack:** Next.js · TypeScript · Supabase · PostgreSQL · Tailwind CSS · Vercel

**Results / metrics:** [preencher]
